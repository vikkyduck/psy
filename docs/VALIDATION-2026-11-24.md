# Проверка релиза от 24 ноября 2026 года

Рабочий исходный код сверили с публичным комплектом по разрешенному списку программ. Проверены 88 исходников, включая установленный расшифровщик, общий модуль, службы и операционные сценарии. Все 29 файлов checkout и общий модуль совпали с пересчитанными манифестами. Полный патч проверен на чистом официальном Hermes `71d34bad1045610252eda02ee79549436896e784`.

В релиз вошли исправления завершения шлюза, ложной тревоги при перезапуске, задержки подтвержденного восстановления и последняя версия группового клиента Codex. Время работы лекции или разбора не ограничено. Таймер финального выхода включается после подтвержденного сохранения состояния, а не по возрасту задания.

Тест большой записи шел от непривилегированного работника в отдельном сетевом пространстве только с `lo`. В примерах нет действующего Telegram-токена. Действующий вход Codex использовался только общим компонентом авторизации без копирования учетных данных в тестовые файлы. Синтетические БД и сообщения существовали во временных каталогах.

После предыдущих реальных перезапусков служба завершилась без принудительного убийства. При тестах из этого релиза повторный перезапуск рабочего шлюза не нужен. Состояние Telegram проверяют через control socket с совпадением PID, а не только по `systemctl active`.

## Пределы результата

Локальный приемник проверяет адресацию, сериализацию Bot API, получение файла и квитанции. Он не подтверждает появление сообщения на телефоне настоящего участника. Рабочая группа не получает тестовых сообщений.

Большой файл содержит короткую искусственную речь с заполнением до 40 секунд. Этот пример проверяет объем, докачку и весь путь распознавания, но не измеряет скорость многочасовой записи.

Публичный CI запускает восстановление и тесты без действующего OAuth. Реальный Codex проверяется отдельно на установленном узле. Повторяемые команды и границы изоляции приведены в [TESTS.md](TESTS.md).

## Проверка связанной платформы

Публичные страница и `/api/healthz` отвечают HTTP 200, API сообщает `status=ok`. Распознавание и embeddings доступны, основные службы и Unix-мост активны, автозапуск включен.

Один вымышленный запрос `17 + 25` прошел через действующий мост платформы к `gpt-6.1-sol`: HTTP 200, ответ `42`, SSE завершен `response.completed`, 2,023 секунды. Мост использовал общий OAuth-компонент ПСИ. Для проверки не создавали пользователя, чат или материал в БД платформы и не вызывали Telegram.

Авторизованный браузерный сценарий загрузки материала и чата этим запросом не проверяется. Страница входа доступна, полную проверку личного интерфейса проводят отдельно в действующей пользовательской сессии.
