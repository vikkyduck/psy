# Изолированное сравнение качества

`quality_compare.py` вызывает реальный Codex через выбранные модули группового
конвейера. Входы зафиксированы в коде и полностью синтетические. Для каждого
варианта нужен отдельный процесс. Отправки в Telegram отсутствуют.

Запуск выполняется от `hermes` установленным интерпретатором Hermes. Переменные
в примере обозначают уже выбранные оператором абсолютные пути. `HERMES_CHECKOUT`
содержит рабочий runtime и существующую общую OAuth-авторизацию. `CANDIDATE_MODULES`
содержит кандидатные модули. `QUALITY_OUTPUT` - заранее созданный каталог с правами
0700, принадлежащий `hermes`, вне runtime, рабочей конфигурации и репозитория.
Секреты не копируются. Модель и рабочие ограничения генерации не меняются.

```sh
timeout --signal=TERM --kill-after=30s 120m "$HERMES_PYTHON" "$QUALITY_HARNESS" \
  --checkout "$HERMES_CHECKOUT" \
  --case lecture180_local --variant baseline --output-root "$QUALITY_OUTPUT"

timeout --signal=TERM --kill-after=30s 120m "$HERMES_PYTHON" "$QUALITY_HARNESS" \
  --checkout "$HERMES_CHECKOUT" --module-dir "$CANDIDATE_MODULES" \
  --case lecture180_local --variant candidate --output-root "$QUALITY_OUTPUT"
```

Для первого запуска подходит `--case short`. Другие сценарии: `concepts`,
`comparison`, `closed_link`, `lecture30_local`, `lecture180_sources`.

## Проверка источников

Для одинаковой пары запросов требуется одинаковый явный список публичных хостов:
повторяемый аргумент `--source-host имя.домена`. Поддомены и хосты перенаправлений
не разрешаются автоматически. Нельзя передавать URL, IP, Telegram или локальный
хост. DNS-ответ с непубличным адресом блокируется. Проверка публичного IP внутри
производственного reader сохраняется.

Без `--allow-pdf` стенд допускает HTML и текст, а PDF исключает. Это ограниченная
проверка доступности источников, ее нельзя считать полной проверкой первоисточников.
С `--allow-pdf` разрешена только точная команда существующего производственного
декодера. Сохраняются seccomp, Landlock, лимиты памяти, CPU и объема. На каждый запуск
проверяются путь и хеш reader, PDF до 8 МиБ, закрытое окружение, таймаут 32 секунды
и приватный выходной файл внутри временной базы. Прямой `Popen` остается запрещен.

Для содержательной приемки проверить `storage_audit.pdf_subprocesses`,
`source_exclusions`, фактически проверенные источники и ответ. Успех HTTP-запроса,
запуск декодера или средний балл сами по себе не доказывают точность цитирования.
Если разрешенный список исключил нужные первоисточники, пару следует оценивать как
сценарий недоступности, а полное сравнение авторов повторить с подходящими источниками.

## Слепая оценка

`review/answer-<случайный код>.txt` содержит задание, учебный материал и ответ.
Оценщику передаются только файлы из `review` в перемешанном порядке.
`keys/answer-<код>.json` хранит соответствие версии, хеши модулей и метаданные.
В выводе CLI нет полного ответа или названия версии. Файлы создаются с правами 0600
без перезаписи существующих файлов и без перехода по символическим ссылкам.

Отдельно оценить выполнение задания, точность, глубину, связность, язык и границы
интерпретации. Придуманная цитата и частичный ответ, представленный полным,
блокируют приемку. Сначала фиксируются оценки, затем раскрывается файл соответствий.
Одна пара не устраняет случайные различия модели и изменение доступности сайтов.

## Границы проверки

Поле `status=generated` означает получение текста. Оно не означает приемку.
`generation_complete` отражает только аудит завершения API, при отсутствии такого
аудита равно null. `legacy_pipeline_complete` сохраняет старый составной флаг
конвейера. Для двух запусков старой версии стенда поле `generation_complete`
имело смысл этого составного флага, их нельзя интерпретировать как аудит API.

Стенд проверяет композицию текста и временные контрольные точки. Он не проверяет
доставку, повторную доставку, привязку ответа к сообщению и финальную очистку очереди.
Эти проверки выполняются отдельно. Отсутствие сохраненного статуса короткого ответа
в composition-only запуске не доказывает ошибку Telegram-маршрута.

При импорте настоящего транспортного helper подавляются только четыре операции
обслуживания entry point: восстановление checkout, подготовка обновления,
восстановление dependency environment и его повторная активация. Уже выбранные
зависимости подключаются для чтения. Happy Eyeballs, OAuth, API и модель остаются
реальными. Число подавленных вызовов сохраняется в `bootstrap.suppressed_calls`.
Завершение внешним `timeout` без ответа является незавершенным прогоном.

Локальные guard-тесты не обращаются к модели, сети или нативному PDF-декодеру:

```sh
python3 -m unittest discover -s tests/isolated -p 'test_*guards.py' -v
```

Они проверяют в том числе соответствие реального вызова `passages` узкому
разрешению subprocess. Работу Linux sandbox и извлечение реального PDF нужно
подтвердить отдельным запуском на сервере.
