# Восстановление шлюза PSY

Основа шлюза - официальный коммит Hermes `71d34bad1045610252eda02ee79549436896e784`. Сценарий ожидает каталог Git с этим HEAD и HTTPS origin NousResearch. Нужен Python 3.9 или новее для установки патча. Для работы Hermes используйте версию Python и изолированную среду из официального установщика этой ревизии. [Исходный коммит](https://github.com/NousResearch/hermes-agent/commit/71d34bad1045610252eda02ee79549436896e784)

На остановленном целевом узле в каталоге этого репозитория выполните следующие команды от владельца checkout. Переменная `CHECKOUT` указывает на каталог установленного Hermes.

```sh
python3 gateway/apply.py apply "$CHECKOUT"
python3 gateway/apply.py verify "$CHECKOUT"
PYTHONDONTWRITEBYTECODE=1 python3 gateway/test_gateway.py "$CHECKOUT"
```

Патч изменяет 7 отслеживаемых файлов Hermes. Установщик добавляет 7 рабочих расширений Telegram и модуль проверки параметров экземпляра. Общий исходник для `psy_upload_handoff.py` хранится в `media/telegram_handoff.py`. После установки `manifest.json` позволяет проверить SHA-256 каждого из 15 файлов. `group-manifest.json` содержит 10 контрольных сумм для проверки границы доступа перед запуском службы. Независимые изменения в целевых файлах прерывают установку. Повторный запуск завершает прерванную установку.

Для проверки тесты используют искусственные идентификаторы, временные базы SQLite и имитацию ответов Codex. Проверяются разрешенные чаты, изоляция участников и тем, загрузка записи, восстановление очереди, обработка исчерпанных квот и выбор OAuth. Тесты не вызывают внешние API.

## Параметры профиля

В `ops/instance.env.example` указаны имена параметров. Установите на целевой машине `PSY_OWNER_ID`, `PSY_GROUP_ID`, `PSY_BOT_ID`, `PSY_BOT_USERNAME` без @ и `PSY_PUBLIC_URL` с HTTPS. Используйте один набор значений для шлюза, загрузчика и служб, выдающих доступ. Конфигурация PSY предназначена для одного бота. Несовпадение его ID при подключении блокирует обработку обновлений.

Сценарий `configure_profile.py` запускается от системного пользователя hermes после установки патча, с переменными экземпляра в окружении. Он использует Telegram-токен из закрытого файла профиля `.env` или из файла `telegram-token.pending` с правами 0600. Проверьте числовой префикс токена по `PSY_BOT_ID`. Привязку подписки выполните через штатный вход Codex по коду устройства. Если восстанавливается существующий пул, используйте актуальную закрытую копию профиля и последовательность переключения из инструкции. [Восстановление узла](../docs/RESTORE.md)

Профиль включает Codex OAuth, режим генерации изображений, локальное распознавание, закрытые личные сообщения, доступ в одну группу, уведомления Telegram и хранение результатов. При настройке с нуля выбирается модель `gpt-6.1-sol`. Для уже настроенного провайдера `openai-codex` сохраняется его модель. Совместимость модели и доступность подписки проверяются после входа. Публичный профиль составлен по конфигураторам и проверкам проекта.
